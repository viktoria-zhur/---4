# CryptoLab — лабораторная работа № 5 «Криптография»

Учебный проект на Python: классические шифры, криптоанализ, LSB-стеганография, SHA-256, AES-GCM, RSA-PSS, учебная модель защищённого сеанса, анализ тестового сетевого журнала и разбор инцидентов.

> **Важно:** классические шифры, LSB и модель TLS предназначены только для обучения. TLS-модуль не реализует протокол TLS. Для практической защиты данных применяются AES-GCM и RSA-PSS из библиотеки `cryptography`, но этот проект не является готовой системой управления ключами.

## Требования

- Python 3.10 или новее
- pip
- `cryptography` (устанавливается из `requirements.txt`)

## Быстрый запуск

Из корневой папки репозитория:

```bash
python -m pip install -r requirements.txt
python main.py все
```

Интерактивное меню:

```bash
python main.py
```

Отдельные команды:

```bash
python main.py классика
python main.py анализ
python main.py стего
python main.py хеш
python main.py подпись
python main.py tls
python main.py инциденты
python main.py дефекты
python main.py тесты
```

## Автоматические тесты

```bash
python -m unittest discover -s tests -v
```

В проекте 36 автоматических тестов. Они проверяют обратимость классических шифров, обработку ошибочных параметров, стеганографию, SHA-256, AES-GCM, RSA-подпись, журнал событий, TLS-демонстрацию и три контрольных негативных сценария. Результаты выполнения сохраняются в `отчёты/`.

## Что реализовано

- Цезарь, Атбаш, Полибий, Виженер, блочная перестановка с точным восстановлением длины, Плейфер и решётка Кардано.
- Частотный анализ и полный перебор ключей шифра Цезаря.
- LSB-встраивание UTF-8 сообщения в массив значений 0–255.
- SHA-256 и проверка целостности.
- AES-256-GCM с новым случайным nonce при каждом шифровании и проверкой тега.
- RSA-2048 / RSA-PSS / SHA-256 для демонстрации электронной подписи.
- Упрощённая учебная модель защищённого сеанса (не TLS-стек).
- Анализ искусственного сетевого журнала и краткие карточки инцидентов.
- Три автоматизированных негативных сценария: некорректный ключ, изменение AES-GCM шифротекста, изменение подписанного документа.

## Примечания по методике

- В шифре Полибия `I` и `J` объединены.
- Плейфер также объединяет `I/J`, удаляет пробелы/пунктуацию и вставляет `X` (или `Q`) между повторяющимися буквами; при учебной расшифровке исходное форматирование автоматически не восстанавливается.
- Перестановка блоков дополняет последний блок пробелами. Для точного восстановления передаётся исходная длина.
- Решётка Кардано принимает квадратную чётную бинарную маску. Четыре поворота должны покрывать каждую ячейку ровно один раз.
- LSB не обеспечивает конфиденциальность и криптографическую целостность.
- В отчётах используются только вымышленные данные и документационные IP-диапазоны.
